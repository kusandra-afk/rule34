Вход через Rule34 API

Для доступа к медиатеке требуется авторизация с вашими параметрами User ID и API Key.

Где найти ключи?
  1. Откройте настройки аккаунта Rule34.xxx (требуется вход).
    Чтобы в этом разделе появился api_key, поставьте галочку Generate New Key и нажмите Save.
  2. Скопируйте ваш числовой user_id и api_key из блока API Access Credentials.
