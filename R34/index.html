Режим для слабых устройств:

Рекомендуется для старых ноутбуков, планшетов и при любых тормозах интерфейса.
Ограничение параллельной загрузки:
• Снижает нагрузку на сетевой канал и процессор при скролле
• Ограничивает количество активных сетевых запросов к серверу
• Позволяет интерфейсу оставаться отзывчивым на слабых устройствах

Рекомендуется при медленном интернете или лагах во время быстрой прокрутки.
Предзагрузка карточек:
• Управляет тем, за сколько пикселей до появления на экране браузер начинает загружать медиа
• Отключить: загружает только когда карточка видна на экране (минимальный расход трафика)
• Рядом с экраном: начинает загрузку за 260-500px до появления (баланс между скоростью и трафиком)
• Следующая страница: начинает загрузку за 700-1200px до появления (максимальная плавность прокрутки)

Рекомендуется "Рядом с экраном" для оптимального баланса.

• Пазлы собираются в более лёгком режиме: меньше деталей
• Упрощаются анимации и снижается нагрузка на GPU
• Полезно для слабых устройств при тормозах в мини-игре

Рекомендуется включить при лагах в пазлах.
Облако и технические настройки
Отображает служебную панель с текущими метриками: количество карточек, активных видео и режим предзагрузки. Это полезно для диагностики и настройки интерфейса, а не для обычной работы.
Turso синхронизация:
• Синхронизирует избранное и пройденные пазлы между устройствами
• Использует SQLite в облаке (Turso) для хранения данных
• Бесплатный tier: 3GB, 500 запросов/день
• Данные доступны с любого устройства
• Если не настроено - используется локальное хранилище

Инструкция по настройке:
1. Перейди на turso.tech и создай бесплатный аккаунт
2. Создай новую базу данных (Create Database)
3. Получи Database URL и Auth Token в настройках базы
4. Введи URL в поле "Turso Database URL"
5. Введи токен в поле "Turso Auth Token"
6. Включи переключатель "Синхронизация через Turso"

• Минимальное значение: 5 сек, Максимальное: 60 сек
• Рекомендуется: 10-20 сек для стабильной работы
• Увеличьте при медленном интернете или частых таймаутах

Пример: При значении 15с запрос будет отменен, если сервер не ответит в течение 15 секунд.
3
Повторные попытки:

• Минимальное значение: 0 (без повторов), Максимальное: 10
• Рекомендуется: 2-5 для надежности
• При значении 0 приложение сразу покажет ошибку при неудаче

Пример: При значении 3 приложение попытается повторить запрос до 3 раз перед показом ошибки.

• Минимальное значение: 1 сек, Максимальное: 30 сек
• Рекомендуется: 1-5 сек для избежания rate limiting
• Большая задержка увеличивает время загрузки при ошибках

Пример: При значении 2с приложение будет ждать 2 секунды между каждой повторной попыткой.

Быстрый инструктаж по поиску и управлению

1

Как искать теги (автозамена пробелов на _)

В базе данных Rule34 все теги пишутся через нижнее подчеркивание _ без пробелов. При вводе пробелы автоматически заменяются на _ для вашего удобства! Также пост можно найти напрямую по его ID в формате id:1234.

Примеры: genshin_impact, hatsune_miku, id:1234567.

2

Кнопка переключения режима + и - слева от поиска

Слева от строки ввода поиска находится специальная кнопка выбора режима (+ / -):

  • + Режим добавления: Нажмите кнопку слева, чтобы включить зеленый плюс +. Все вводимые или выбираемые из автопоиска теги будут включаться в поиск.
  • - Режим исключения: Нажмите кнопку слева, чтобы переключить на красный минус -. Все вводимые или выбираемые теги будут исключаться из поиска.
3

Управление активными тегами (над строкой поиска)

Все выбранные теги отображаются над строкой поиска в виде цветных плашек:

+genshin_impact -animated
  • Клик по включенному (зеленому) тегу: Выключает тег и переводит его в исключенные (красная плашка).
  • Повторный клик по выключенному (красному) тегу: Полностью удаляет тег из поиска.
  • Зажатие (Long Press) или Shift+клик по выключенному тегу: Перемещает его обратно во включенные теги (зеленая плашка).
  • Продвинутые настройки: В разделе «Настройки» → «Продвинутые настройки» (параметр «Поведение клика по тегу») можно изменить этот логический режим (напр. переключать кликом, двойным кликом или зажатием).
4

Управление тегами под медиафайлами

При нажатии на медиа открывается блок с тэгами.

🖥️ На компьютерах (ПК):
  • Левый клик (ЛКМ) — добавляет тег во включенные (+).
  • Правый клик (ПКМ) — добавляет тег в исключенные (-).
📱 На телефонах (Touch):
  • Быстрый тап — добавляет тег во включенные (+).
  • Долгое зажатие (Long Press) — переключает его в исключенные (-).
