скоростью, ни поведением на телефоне. Поэтому здесь свой фронтенд, свои темы и полностью
локальный сервер — данные и ключи не покидают вашу машину.

## 🚀 Быстрый старт

### Android (Termux)

```bash
# 1. Дать Termux доступ к файлам (один раз)
termux-setup-storage

# 2. Найти папку проекта и перейти в неё
find /storage/emulated/0 -type d -name "rule34" | head -n 1
cd /storage/emulated/0/ПУТЬ/К/rule34

# 3. Запуск: доустановит зависимости и поднимет сервер
sh run_termux.sh
```

> Первый запуск долгий: Termux ставит Python, Rust и Clang, а потом собирает
> криптографические пакеты. Дальше запуск занимает секунды.

### Windows

1. Установите [Python 3.8+](https://www.python.org/downloads/windows/) — при установке
   отметьте **Add python.exe to PATH**.
2. Запустите `run_windows.bat` — он проверит Python, поставит зависимости и стартует сервер.

### Linux / macOS

```bash
pip install -r requirements.txt
python server.py
```

### Открыть в браузере

```
http://127.0.0.1:3000
```

Телефон или другой ПК в той же сети — по адресу `http://<ip-в-сети>:3000` (сервер печатает
его при запуске). Для этого нужен режим `lan`, см. ниже.

При первом открытии попросит **user_id** и **API-ключ rule34**. Оба берутся в
[настройках аккаунта rule34.xxx](https://rule34.xxx/index.php?page=account&s=options)
(нужен вход; чтобы появился `api_key`, поставьте галочку **Generate New Key** и нажмите **Save**) — пошаговая
подсказка есть прямо на странице входа. Ключи хранятся зашифрованными в `R34/.secrets/`.
Выйти и сбросить сохранённые ключи можно по адресу `/logout`.

> Команды в блоках выше — шпаргалка для терминала, их запускаете вы сами. Скрипты
> `run_termux.sh` и `run_windows.bat` тоже запускаются вручную, каждый в своей системе.

## ⚙️ Параметры запуска

| Флаг | Что делает |
|---|---|
| `--port`, `-p` | Порт (по умолчанию `3000`) |
| `--host`, `-H` | Адрес привязки; перебивает выбор режима |
| `--mode`, `-m` | `local` — только этот компьютер (`127.0.0.1`), `lan` — доступ из локальной сети (`0.0.0.0`) |
| `--lang`, `-l` | Язык интерфейса: `ru` или `en`. Сохраняется и используется при следующих запусках |
| `--https` | HTTPS с самоподписанным сертификатом. Нужен для гироскопа и WebXR с телефона: браузеры отдают их только в защищённом контексте |

При самом первом запуске сервер спросит язык (`1` — русский, `2` — English), а затем режим
доступа (`1` — только этот компьютер, `2` — вся локальная сеть). Язык сохраняется, поэтому
второй раз его никто не спросит.

```bash
python server.py --mode lan --https --port 3000
```

## 🎮 Игры

**Как открыть:** нажмите **5 раз по заголовку сайта** — откроется окно выбора игры.

### 🧩 Пазл

Картинка из галереи режется на фрагменты, есть несколько уровней сложности, таймер,
перемешивание и сбор прогресса. Работает и офлайн, и вдвоём-вчетвером по сети.

### 🌐 Онлайн

- **Транспорт** — WebRTC, поэтому между устройствами в разных сетях (за NAT) может
  понадобиться TURN-релей: ключ Metered вводится в окне онлайн-игры, вместе с инструкцией.
- **Сигналинг** — публичный брокер PeerJS (`0.peerjs.com`). Если он недоступен у вашего
  провайдера, комната не создастся: приложение покажет `Lost connection`. Помогает VPN.
- **Переподключения нет**: обновление страницы, закрытие вкладки или сон устройства
  разрывают сессию. Если хост уходит — комната закрывается для всех.

### 🎲 Больше/меньше

Экспериментальная игра внутри того же окна. Разработка остановлена — работает нестабильно,
желающие могут довести до ума.

## 🌐 Язык интерфейса

Интерфейс переключается между русским и английским без перезагрузки страницы —
**Настройки → Система и данные → Язык интерфейса**. Выбор сохраняется в браузере, в общих
настройках и на сервере, так что он приезжает и на другие устройства.

Язык старта сервера лежит в `R34/.secrets/language.json`. Удалите этот файл, если хотите,
чтобы при следующем запуске сервер снова спросил язык; либо задайте его флагом `--lang en`.

Английские строки живут в [R34/static/js/i18n/locales/en.js](R34/static/js/i18n/locales/en.js):
словарь — это пары «русский текст → английский». Основная часть интерфейса переведена;
если какая-то подсказка осталась на русском — достаточно добавить одну строку в этот файл,
менять разметку не нужно.

## 🎨 Темы и оформление

В настройках есть готовые **пресеты тем** (они меняют и фон, и акцентные цвета сразу) и
**свой акцентный цвет** для точечной подстройки. Плюс: шрифт интерфейса и базовый масштаб,

анимаций и экспертный редактор стилей для тонкой правки.

## 🔐 Данные и приватность

- Сервер слушает только вашу машину или вашу сеть — никаких внешних сервисов для работы
  галереи не требуется.
- API-ключ rule34 хранится зашифрованным в `R34/.secrets/` и не отдаётся в браузер.
- Доступ к пользовательским ручкам `/api/*` прикрыт cookie-сессией: посторонний компьютер в
  той же сети не прочитает настройки и избранное, не проходя страницу входа.
- Телеметрии и аналитики нет. Turso включается вручную и только по вашему токену.
- Внешние соединения бывают только там, где без них нельзя: запросы к rule34.xxx,
  сигнальный брокер PeerJS и TURN-релей Metered (если вы указали ключ).

> **Не выкладывайте папку `R34/.secrets/` в публичный репозиторий** — там ваши ключи,
> избранное и настройки.

## 🧯 Решение проблем

| Проблема | Что делать |
|---|---|
| `Lost connection to server` при создании комнаты | Брокер PeerJS недоступен (блокировка провайдера/Cloudflare). Включите VPN или попробуйте позже |
| Онлайн не соединяется между разными сетями | Нужен TURN-ключ Metered — вводится в окне онлайн-игры |
| Порт занят | `python server.py --port 3001` |
| Телефон не открывает адрес `192.168.*` | Сервер запущен в режиме `local`. Запустите с `--mode lan` |
| Браузер ругается на сертификат | Он самоподписанный и локальный: «Дополнительно» → «Перейти на сайт». Предупреждение принимается один раз |
| Не работают гироскоп и VR с телефона | Нужен `--https` или доступ через `localhost` |
| Просит вход заново / не пускает | Откройте `/logout` и введите `user_id` с API-ключом заново |
| Подлагивает на слабом телефоне | Включите «Режим для слабых устройств», уменьшите число колонок и предзагрузку карточек |

## 🤝 Участие

Проект полностью написан бесплатными ИИ-моделями — отсюда местами неровный код. Если нашли
баг или хотите что-то улучшить: форк, правка, pull request. Любая помощь приветствуется —
это и есть причина, по которой проект открыт.
- **Продолжение пазла.** Незаконченная соло-сборка сохраняется раз в 4 секунды (позиции деталей, группы, время и ходы) и появляется в меню пазлов кнопкой «Продолжить пазл» — 24 часа.
- **Просмотренные посты.** Открытые в полноэкранном режиме карточки приглушаются в ленте (в `localStorage` только id, до 3000 записей).
- **История поиска.** Пустое поле тегов показывает последние 10 запросов, их можно удалять по одному.
- **Тесты и версии.** `python -m unittest discover -s tests -v` — 6 smoke-тестов без внешних зависимостей; `requirements.lock` фиксирует проверенные версии пакетов.
