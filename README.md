## 🚀 УСТАНОВКА И ЗАПУСК НА ANDROID (TERMUX)

1.  Разрешите Termux доступ к хранилищу (Если вы этого не сделали)
   ▸ termux-setup-storage  

2. 🔍 Найдите путь к папке проекта (пример «rule34»)  
   ▸ find /storage/emulated/0 -type d -name "rule34" | head -n 1  

3. 📂 Перейдите в папку проекта  
   ▸ cd /ПУТЬ/ИЗ/ШАГА/2

4. 🚀 Запустите файл быстрого запуска (автоматически установит зависимости и запустит сервер)
   ▸ sh run_termux.sh  
   💡 (может занять много времени при первой установке)

5. 🌐 Откройте приложение в браузере  
   ▸ http://127.0.0.1:3000
   ▸ или же второй вариант ip (могут зайти все устройства подключенные к одно сети)

## 🎮 ИГРЫ!

В приложении пока доступно две игры "Пазл" и "Больше или Меньше" с поддержкой онлайн-режима для игры с друзьями.

### 🌐 Как играть?

      **В главном меню нажмите 5 раз по заголовку сайта**

### 💡 Важные нюансы относящийся к мультиплееру:
- **Нужна регистрация**: Инструкция есть в разделе выбора игры.
- **Совместное использование ключа**: Один человек может зарегистрировать ключ и просто раздать его друзьям — он будет работать у всех, регистрация каждому не обязательна.
- **ВАЖНО!**: бесплатный ключ имеет лимиты 100 одновременныйх подключений и 100,000 сообщений, обновляется раз в месяц.
- **Безопасность**: Ваш ключ хранится локально в кэше браузера и не передается на сторонние серверы, кроме сигнального сервера Metered.
- **Закрытие сессии**: Если хост покидает игру, комната закрывается для всех. Если все игроки выходят, сессия завершается автоматически.
