## 🚀 УСТАНОВКА И ЗАПУСК НА ANDROID (TERMUX)

1.  Разрешите Termux доступ к хранилищу (Если вы этого не сделали)
   ▸ termux-setup-storage  

2. 🔍 Найдите путь к папке проекта (пример «rule34», если пишет "too many arguments" то переименуйте папку на более короткое название)  
   ▸ find /storage/emulated/0 -type d -name "rule34" | head -n 1  

3. 📂 Перейдите в папку проекта  
   ▸ cd /ПУТЬ/ИЗ/ШАГА/2

4. 🚀 Запустите файл быстрого запуска (автоматически установит зависимости и запустит сервер)
   ▸ sh run_termux.sh  
   💡 (может занять много времени при первой установке)

5. 🌐 Откройте приложение в браузере  
   ▸ http://127.0.0.1:3000
   ▸ или же второй вариант ip (могут зайти все устройства подключенные к одно сети)

   В моем случае чтобы сервер функционировал нормально Termux надо поставить в плавающее окно и смахнуть влево
   чтобы он стал иконкой на конце экрана (я хз как это еще описать)
